# USB权限管理器 - 看门狗功能说明

## 🛡️ 看门狗功能

### 功能概述
看门狗功能确保USB权限管理器持续运行，防止被非法关闭或终止，只有管理员才能正常退出程序。

### 🔒 安全特性

#### 1. 权限控制
- **未认证用户**：无法关闭程序
- **访问员**：无法关闭程序，只能查看状态
- **管理员**：可以正常关闭程序

#### 2. 信号保护
- 拦截 `Ctrl+C` 中断信号
- 拦截系统终止信号
- 防止任务管理器强制关闭

#### 3. 窗口保护
- 禁用窗口关闭按钮（X按钮）
- 只能通过菜单"退出程序"退出
- 关闭时需要管理员权限确认

### 🎯 使用方法

#### 正常启动
```bash
python usb_manager_enhanced.py
```

#### 管理员退出流程
1. 以管理员身份登录
2. 点击菜单：用户 → 退出程序
3. 确认关闭对话框
4. 程序正常退出

#### 系统托盘（可选）
如果安装了 `pystray` 库：
```bash
pip install pystray pillow
```
- 关闭窗口时自动最小化到系统托盘
- 托盘图标可重新显示主窗口
- 托盘菜单可完全退出程序

### 🚨 安全警告

#### 访问员尝试退出
- 显示"权限不足"警告
- 程序继续运行，无法关闭

#### 未登录用户尝试退出
- 显示"请先登录"警告
- 程序继续运行，无法关闭

#### 强制终止保护
- 任务管理器无法直接终止
- 命令行kill命令被拦截
- 系统重启前程序持续运行

### 📋 部署建议

#### 1. 开机自启动
创建Windows服务或启动项：
```cmd
# 创建启动项
reg add "HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run" /v "USBManager" /t REG_SZ /d "pythonw.exe D:\编程\源码包\禁用USB\usb_manager_enhanced.py"
```

#### 2. 后台运行
使用 `pythonw.exe` 启动，不显示控制台窗口：
```cmd
pythonw.exe usb_manager_enhanced.py
```

#### 3. 服务化部署
推荐使用NSSM将程序注册为Windows服务，提供更高级的保护。

### ⚙️ 配置选项

#### 看门狗检查间隔
默认每秒检查一次，可在代码中调整：
```python
time.sleep(1)  # 调整检查间隔
```

#### 退出权限控制
全局变量 `exit_allowed` 控制是否允许退出：
```python
exit_allowed = True  # 允许退出
exit_allowed = False  # 禁止退出
```

### 🔧 故障排除

#### 程序无法启动
- 检查Python环境
- 确认依赖库安装完整
- 查看错误日志

#### 无法正常退出
- 确认使用管理员账户登录
- 通过菜单"退出程序"退出
- 避免使用任务管理器强制结束

#### 系统托盘不显示
- 安装依赖：`pip install pystray pillow`
- 重启程序
- 检查系统托盘设置

### 📞 技术支持

如遇到问题，请检查：
1. 程序是否以管理员权限运行
2. 是否正确登录管理员账户
3. 系统是否支持看门狗功能
4. 相关依赖库是否正确安装

---

**注意**：看门狗功能旨在保护USB安全管理，请妥善保管管理员密码，避免被恶意利用。
