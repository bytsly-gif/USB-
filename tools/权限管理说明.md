# USB存储设备权限管理器

## 功能概述

本软件提供了完整的USB存储设备权限管理功能，支持两种用户权限级别：

### 🔐 权限级别

#### 访问员权限
- **读取权限**：可以读取U盘中的文件
- **写入限制**：无法向U盘写入、修改或删除文件
- **设置限制**：无法修改USB设备的启用/禁用状态
- **自动保护**：登录时自动启用USB写入保护

#### 管理员权限
- **完全控制**：可以读写U盘中的所有文件
- **设置权限**：可以启用/禁用USB存储设备
- **密码管理**：可以修改管理员密码
- **保护控制**：登录时自动禁用USB写入保护

## 📁 文件说明

### 主要程序文件

1. **usb_manager_complete.py** - ⭐ 完整版本（推荐）
   - 集成权限管理、USB控制、访问监控
   - 支持访问员和管理员两种权限
   - 自动应用写入保护策略

2. **usb_manager_enhanced.py** - 增强版本
   - 基础权限管理功能
   - 管理员密码验证
   - USB设备控制

3. **usb_manager.py** - 基础版本
   - 原始的USB控制功能
   - 无权限管理

4. **usb_access_monitor.py** - 访问监控器
   - 独立的USB访问监控功能
   - 写入保护控制

### 辅助文件

- **start_usb_manager.bat** - 启动脚本
- **admin_password.json** - 管理员密码存储文件（自动生成）

## 🚀 使用方法

### 方法一：使用启动脚本（推荐）
```bash
start_usb_manager.bat
```

### 方法二：直接运行
```bash
python usb_manager_complete.py
```

## 📋 使用流程

### 首次使用

1. **启动程序**
   ```bash
   python usb_manager_complete.py
   ```

2. **管理员登录**
   - 点击"管理员登录"
   - 输入默认密码：`admin123`
   - 登录成功后建议立即修改密码

3. **修改管理员密码**
   - 菜单栏 → 设置 → 修改管理员密码
   - 输入当前密码和新密码
   - 确认修改

### 日常使用

#### 访问员使用场景
1. 点击"访问员登录"
2. 系统自动启用USB写入保护
3. 可以读取U盘文件，但无法写入
4. 无法修改USB设备设置

#### 管理员使用场景
1. 点击"管理员登录"
2. 输入管理员密码
3. 获得完全控制权限
4. 可以读写U盘和修改USB设置

## 🔧 技术实现

### 权限控制机制

1. **写入保护**：通过Windows注册表实现
   ```
   注册表路径：HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\StorageDevicePolicies
   键值：WriteProtect (0=禁用, 1=启用)
   ```

2. **USB设备控制**：通过服务启动类型控制
   ```
   注册表路径：HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USBSTOR
   键值：Start (3=启用, 4=禁用)
   ```

3. **密码存储**：使用SHA256哈希加密存储
   ```
   文件位置：admin_password.json
   存储格式：{"admin_password": "sha256_hash"}
   ```

### 安全特性

- ✅ 密码哈希存储，明文不保存
- ✅ 访问员自动写入保护
- ✅ 权限分离，最小权限原则
- ✅ 登出时自动清理权限设置

## ⚠️ 注意事项

### 系统要求
- Windows操作系统
- Python 3.6或更高版本
- 管理员权限（用于修改注册表）

### 安全提醒
- 首次使用请立即修改默认密码
- 管理员密码请妥善保管
- 访问员权限适合临时使用场景

### 兼容性
- 支持Windows 7/8/10/11
- 兼容所有USB存储设备
- 不影响USB键盘、鼠标等输入设备

## 🔍 故障排除

### 常见问题

1. **无法启用写入保护**
   - 确保以管理员权限运行程序
   - 检查注册表访问权限

2. **密码验证失败**
   - 检查密码文件是否存在
   - 尝试使用默认密码 `admin123`

3. **USB设备控制无效**
   - 需要重新插拔USB设备
   - 可能需要重启计算机

### 重置方法

如果忘记管理员密码，可以删除 `admin_password.json` 文件，程序将恢复默认密码。

## 📞 技术支持

如有问题，请检查：
1. Python环境是否正确安装
2. 是否以管理员权限运行
3. 防病毒软件是否阻止程序运行
